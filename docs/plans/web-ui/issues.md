# Web UI 界面 — Issues

> 创建时间：2025-09-14

## 问题分解

每个 issue 是一个垂直切片，贯穿所有集成层的端到端路径。

### Issue 1: 项目骨架与 Gradio 基础框架

**类型**: AFK
**依赖**: None

**端到端行为**:
创建 `app.py` 入口文件，初始化 Gradio 应用，包含三个 Tab（上传、训练、合成）。每个 Tab 有基本的占位组件。运行 `python app.py` 后浏览器可访问，看到完整的三栏布局。

**如何验证**:
运行 `python app.py`，浏览器打开显示三个 Tab，每个 Tab 有占位文本。

**验收标准**:
- Given 用户运行 `python app.py`，When 浏览器打开 `http://localhost:7860`，Then 看到三个 Tab：「上传音频」「训练模型」「合成语音」
- Given 用户切换 Tab，When 点击不同标签，Then 对应内容正确显示

**阻塞项**: 无

**解决的用户故事**: 全部（基础设施）

---

### Issue 2: 音频上传与预处理

**类型**: AFK
**依赖**: Issue 1

**端到端行为**:
用户在「上传音频」Tab 拖拽或选择音频文件，系统接收文件、校验格式（WAV/MP3/FLAC）、检查时长，将文件保存到 `workspace/uploads/`，显示文件列表（文件名、时长、大小）。

**如何验证**:
拖拽一个 .wav 文件到上传区，文件出现在下方列表中，显示正确的时长和大小。上传一个 .txt 文件，显示格式错误提示。

**验收标准**:
- Given 用户拖拽 .wav 文件，When 上传完成，Then 文件出现在列表中，显示文件名、时长（秒）、大小（KB）
- Given 用户上传 .txt 文件，When 文件被接收，Then 显示红色错误提示「仅支持 WAV/MP3/FLAC 格式」
- Given 用户上传 2 秒的音频，When 校验完成，Then 显示黄色警告「音频过短，建议至少 10 秒」
- Given 用户上传 >500MB 文件，When 上传开始前，Then 拒绝并提示「文件过大」

**阻塞项**: Issue 1

**解决的用户故事**: US-1

---

### Issue 3: 模型训练与进度监控

**类型**: AFK
**依赖**: Issue 2

**端到端行为**:
用户在「训练模型」Tab 点击「开始训练」，系统启动 GPT-SoVITS 训练子进程，页面显示实时进度条和滚动日志。训练完成后模型自动保存到 `workspace/models/`，状态变为「训练完成」。支持取消训练。

**如何验证**:
上传音频后点击训练，进度条从 0% 增长到 100%，日志滚动更新。完成后模型出现在模型列表中。

**验收标准**:
- Given 用户已上传音频，When 点击「开始训练」，Then 按钮变为「训练中...」并禁用，进度条开始增长
- Given 训练进行中，When 用户查看日志区域，Then 显示滚动更新的训练日志
- Given 训练进行中，When 用户点击「取消训练」，Then 子进程被终止，状态回到初始
- Given 训练完成，When 用户查看页面，Then 显示「✅ 训练完成」，模型自动出现在合成页的模型下拉框中
- Given 没有上传音频，When 用户查看训练页，Then 显示提示「请先上传音频」

**阻塞项**: Issue 2

**解决的用户故事**: US-2

### Issue 4: 语音合成与播放下载

**类型**: AFK
**依赖**: Issue 3

**端到端行为**:
用户在「合成语音」Tab 输入文本、从下拉框选择已训练模型，点击「合成」按钮。系统调用 GPT-SoVITS 推理，生成音频文件，页面显示音频播放器并自动播放。提供下载按钮。

**如何验证**:
选择模型、输入文字、点击合成，几秒后音频播放器出现并自动播放。点击下载按钮，浏览器下载 .wav 文件。

**验收标准**:
- Given 用户选择模型并输入文本，When 点击「合成」，Then 按钮显示「合成中...」，完成后音频播放器出现并自动播放
- Given 合成完成，When 用户点击「下载」，Then 浏览器下载 .wav 文件
- Given 没有已训练模型，When 用户进入合成页，Then 模型下拉框为空，显示提示「请先训练模型」
- Given 文本超过 500 字，When 用户点击合成，Then 显示警告提示

**阻塞项**: Issue 3

**解决的用户故事**: US-3

---

### Issue 5: 模型管理（查看/删除）

**类型**: AFK
**依赖**: Issue 3

**端到端行为**:
在「合成语音」Tab 的模型下拉框旁，添加模型管理区域。显示已训练模型列表（名称、训练时间、大小），支持重命名和删除。删除需二次确认。

**如何验证**:
训练多个模型后，模型列表正确显示。点击删除，弹出确认框，确认后模型被移除。

**验收标准**:
- Given 用户有已训练模型，When 查看模型列表，Then 显示名称、训练时间、文件大小
- Given 用户点击重命名，When 输入新名称并保存，Then 模型名称更新
- Given 用户点击删除，When 确认对话框中点击「确认」，Then 模型被删除，列表更新
- Given 用户点击删除，When 点击「取消」，Then 无操作

**阻塞项**: Issue 3

**解决的用户故事**: US-4
